# Робота із версійністю баз даних за допомогою Liquibase

## Опис проекту

Цей проект демонструє використання інструменту **Liquibase** для
керування версіями бази даних PostgreSQL.

В рамках роботи: - використано базу даних "rest" (тематика: туризм) -
налаштовано підключення Liquibase до БД - реалізовано changelog-файл із
changeSet'ами - виконано оновлення (update) та відкат (rollback) -
згенеровано changelog із існуючої БД

------------------------------------------------------------------------

## Використані технології

-   **Liquibase** - (Community Edition) — система керування версіями баз даних
-   **PostgreSQL** - система управління базами даних
-   **pgAdmin 4** - інструмент адміністрування БД
-   **JDBC Driver** - програмний компонент, який дозволяє Java-додаткам взаємодіяти з базами даних
-   **Git + GitHub** - контроль версій коду

------------------------------------------------------------------------

## Встановлення та налаштування

### 1. Встановлення Liquibase

1.  Завантажити Liquibase Community:
    https://www.liquibase.com/download-community

2.  Додати Liquibase до PATH

3.  Перевірити:

```
    liquibase --version
```

------------------------------------------------------------------------

### 2. Встановлення драйвера PostgreSQL

https://jdbc.postgresql.org/download/

Помістити файл у:

    <LIQUIBASE_HOME>/lib

------------------------------------------------------------------------

### 3. Структура проекту

    IPZ_RGR/
    ├── liquibase/
    │   ├── changelog.xml          # Основний файл змін бази даних
    │   └── liquibase.properties   # Налаштування підключення до БД
    ├── README.md
    └── (інші файли проєкту)

------------------------------------------------------------------------

## Налаштування БД у файлі "liquibase.properties"

    changeLogFile: changelog.xml
    url: jdbc:postgresql://localhost:<your_port>/<name_of_your_DB>
    username: <your_login>
    password: <your_password>
    driver: org.postgresql.Driver


------------------------------------------------------------------------

## Команди

### Перевірка підключення: `liquibase status --changelog-file=changelog.xml`

### Застосування змін: `liquibase update --changelog-file=changelog.xml`

### Додавання тегу: `liquibase tag --tag=version_with_data`

### Відкат змін: `liquibase rollbackCount 1 --changelog-file=changelog.xml`

### Генерація changelog: `liquibase generateChangeLog --changelog-file=changelog.xml`

## Переваги використання Liquibase

-   Повний контроль версій схеми бази даних
-   Можливість працювати в команді без конфліктів

-   Автоматизація розгортання БД
-   Історія всіх змін у текстовому форматі
